## スキルセットの強み・アピール

### 1. 幅広い技術領域をまたいで実装できること

フロントエンド、バックエンド、インフラを分断せずに扱えるため、PoCから本番運用までを一貫して進められます。
新しい技術やアーキテクチャへの適応も早く、既存システムの制約が強い現場でも現実的な落としどころを作ることができます。

### 2. 生成AI・LLM応用を実装まで落とし込めること

社内チャットボット、会議効率化支援、議事録作成支援などの業務支援系プロダクトに加え、LangChainを利用したワークフロー設計や、VLMを利用したロボット制御・マルチモーダル処理にも対応できます。
単なるAPI利用に留まらず、周辺システム設計や運用を見据えた形で組み込むことを重視しています。

### 3. レガシー改善と移行に強いこと

Railsをはじめとした既存システムの改善、バージョンアップ、開発体制の立て直しに継続して関わってきました。
全面刷新だけでなく、現場に合わせて段階的に改善を進めるアプローチを得意としています。

### 4. 研究と実務を接続できること

強化学習、ネットワーク分析、画像処理などの研究経験があり、理論を理解したうえで実装へ落とし込むことができます。
研究寄りのテーマでも、実装・検証・発表まで含めて進められる点が強みです。
